# 統計仕様 v0.1

## 分母と抽出

100万語あたり頻度は、指定したscopeの整数CoNLL-Uノード数からPUNCT/SYMを除いた値を分母にする。NUM等は含む。範囲ID・空ノードは数えない。

関連度の母集団は**同一relationの辺**。N=辺総数、a=指定lemmaを左辺に持つ辺数、b=指定collocateを右辺に持つ辺数、c=その組み合わせ数。単語頻度と辺頻度を混ぜない。原文のverb token頻度とは異なる。

対象は基本依存構文。能動態の名詞目的語 `obj` を `dobj` に正規化。PROPNも含むが代名詞は含めない。受動態の `nsubj:pass` は別relation。並列や省略の復元、語義分割は行わない。誤解析はKWIC監査の対象。

## 関連度

- 期待数 E=a×b/N
- PMI=log2(c/E)
- MI3=log2(c³/E)
- t-score=(c−E)/√c
- Dice=2c/(a+b)
- logDice=14+log2(Dice)
- G²=2Σ O log(O/E)、2×2表は [c,a−c,b−c,N−a−b+c]

c=0でPMI・MI3・t-score・logDiceを架空の有限値にしない。NULLを返す。G²は引力/回避の向きを別フィールドで示す。

## 分散

文書数・ドメイン数・section数・著者ラベル数（著者グループも含む）を保持する。欠損を未知の新規著者として数えない。話者識別は未実装。

文書HHI=Σ(各文書の出現比率)²、有効文書数=1/HHI、ドメインについても同様。DP=0.5Σ|文書ごとの出現比率−文書語数比率|。DPは未出現文書も含む。文書が細かいコーパスでは希少語のDPが1に近づくため、単独で判定しない。

原典ドメインはURL hostname。多数の文書が同一サイト由来ならドメイン数は増えない。同一URLの別スニペットや近似重複は独立性を保証しない。完全一致以外の重複除去は次段階。

配布ファイルをsegment、原典URL（URLデコード・fragment除去）とsourceの組をsource documentとして分離する。同一原典の複数segmentは文書頻度・HHI・DP・KWIC選択で1文書にまとめる。語数・用例数はsegmentの合計。元URLが不明なときだけsegment IDにフォールバックする。alias URLや転載まで同一視する近似重複処理は未実装。

## 比較と負の証拠

宣言した類義語集合Wの中で、対象目的語に関する総数T、動詞vとの組み合わせc、動詞vの全目的語辺a、集合Wの全目的語辺Aを計算する。

- 観測share=c/T
- 基準share=a/A
- lift=観測share/基準share
- preference score=観測share/(観測share+基準share)

preference scoreの0.5は独立モデルと同じ選好、0に近いほど基準より少ない。列ごとの和は1ではない。実例ゼロでも強い判断ができるとは限らず、T=0ならNULL。c/Tの95% Wilson区間も返す（基準shareの不確実性はモデル化していない）。

期待数の方式を分けて保持する。

複数コーパスを扱う拡張以降、以下の層sはsource×registerとする。同ジャンルというだけで、異なる資料・解析器を同一の層にまとめない。

1. 全体の独立モデル：T×a/A。
2. ジャンル層別モデル：Σ_s T_s×a_s/A_s。
3. 支持のある層だけの保守的期待数：方式2のうち対象動詞の辺が10件以上ある層だけを合計。

absence=ln(期待数+1)−ln(観測数+1)。方式1・2を別々に保存。LLM由来のsemantic similarity係数は入れない。

`strongly dispreferred` は全条件を満たす場合に限る。

- 対象動詞が集合内で少なくとも50目的語辺を持つ。
- 目的語の集合内辺が40件以上、15文書以上。
- 方式1と方式3の期待数がともに10以上。
- shareの95% Wilson上限が基準shareの25%未満。
- 独立binomialモデルの下側確率にBonferroni補正を適用し、0.01未満。

比較表では「提示する目的語×動詞」、gap探索では「探索集合の目的語総数×動詞数」を補正familyとする。単一phrase検査は1。複数のphraseを外部で大量試行する場合は別途family管理が必要。

これは真の母語話者集団に関する有意検定ではなく、探索的なコーパスモデル。反復用例・同一サイトの依存、基準share推定、語義交絡の不確実性を完全には扱えない。全条件を満たしても意味的な置換可能性は `unverified` と表示する。相対的回避は文法違反の証拠ではない。

## 分類

1. 上の負の証拠条件を満たす → strongly dispreferred（この標本・集合内の相対選好）。
2. c≥50、文書≥20、文書HHI≤0.1 → common。
3. c≥10、文書≥8、文書HHI≤0.25 → normal。
4. c≥3、文書≥3 → marked。
5. c>0 → rare but attested。
6. その他 → insufficient data。

likely anomalousは独立した正解検証を必要とする予約カテゴリ。ゼロ件からは付与しない。
common/normal等はこの標本の記述分類であって、英語全体の較正済み評定ではない。

## 実験スコア

頻度成分min(1,ln(1+c)/ln101)、関連度成分clip(logDice/14,0,1)、分散成分min(1,文書数/20)×(1−文書HHI)×min(1,有効ドメイン数/5)、選好成分preference scoreを重み付き幾何平均して100倍する。
重みは設定ファイルで0.2/0.2/0.3/0.3。0成分の対数計算では0.001にクリップ。c≥3かつ文書≥3を満たさない場合はスコアNULL。存在しない比較集合の成分は省いて残りの重みを再正規化する。

register breadthとrecencyは、この資料の構成偏りや欠損を考慮してスコアに入れずNULL。分布・分母・年代の観測値は別途返す。自然会話や現代語を含まない標本で高評価を保証しない。星表示は未実装。

## 再現性と評価

固定commit、ファイルごとのSHA256、原典URL、原文条件、注釈条件、完全重複除去履歴を保存する。パイプラインは巨大全文をPostgreSQLに入れず、DuckDBにローカル保存し、Parquetへ出力できる。

合成データはtests専用で、研究DBには混ぜない。テストは非隣接抽出、受動態分離、範囲ID/空ノード除外、関連度の式、区間・下側確率、完全重複、scope分母、集中出現、ジャンル交絡、HTTP経路を検証する。実コーパスの件数を期待値でハードコードしてテストを通すことはしない。

## 全量拡張時の保存・検索

schema v3では、occurrencesをrelation/lemma/collocate/document_id順に並べ、メモリを多く使う巨大な行索引の代わりにDuckDBのzone mapを利用する。集計はrelationごとに分け、入力は小分けにcommitする。完成したファイルだけを既定DBへ切り替える原則は維持する。

出典・register・年・国ごとのpair_strataを保持し、範囲指定時の件数を再利用する。scopeなしではpairsをそのまま参照する。全文forms_jsonをscopeごとにコピーせず、KWICに選ばれた文書だけ読み込む。これらは保存・実行方法の変更であり、頻度の分母や判定閾値は変更しない。

OANCでは配布原文と.ancヘッダーを使う。刊行年はsourceDesc/pubDateから取得し、ヘッダー作成年では代用しない。壊れたヘッダーは原文とエラーを保存して、年・著者を不明のままにする。米語資料としてのコーパス設計と、個々の話者・文書の方言が確認済みであることは区別する。

OANCの書籍ではsource_document_keyを使い、同じISBNの章を1冊にまとめる。旅行ガイドでは配布コレクション・原典書名・出版社・刊行日が同じ節を1冊にまとめる。それ以外は既存の原典URL/文書IDの方針を使う。source_urlはKWICの該当ファイルを示すため保持する。本文・用例数を減らす処理ではなく、文書頻度と集中度の単位を原典に合わせる処理である。
